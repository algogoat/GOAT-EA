name: goat-seed-research
description: Prepare, observe and report bounded GOAT Seed Farming template-by-asset research using the dedicated installed seed commands and their qualification evidence.
---

Read [the portable Seed Farming workflow](../../SEED-WORKFLOW.md). Require the
installed `seed-prepare/start/status/resume/cancel/report` capabilities and check
their current native qualification status. Use the controller's `seed-*` commands
unless the terminal's session says `authority_kind: demo_direct` (a GOAT-owned
demo-agent installation); only there use the broker-verified `demo_agent.py seed-*`
tools, and run `seed-validate` on every new plan first; it writes nothing. Ordinary forward/export batches and
dedicated Seed Farming are different execution modes; do not substitute one for
the other. If native qualification is absent, begin only with the authorized small
demo qualification described by the installed guide.

Freeze the actual template-by-asset count, dates, model, frame/candidate budget,
cutoff and selection rule. Use OHLC for ordinary screening unless the user chooses
another model. Include unsuccessful and incomplete attempts in the ledger. A user
cutoff ends the search; broader prior scope does not extend it.

Compare candidates by canonical trading inputs and exact source hashes, not Pass
number or filenames. Keep development windows, reused history and untouched
validation separate. Do not repeatedly retune against held-out data or discard
forced-liquidation losses to improve reported results.

Use only scoped supported cleanup for the selected worker and preserve downloaded
history, unrelated terminals, grants, live controls and result evidence. Verify the
handoff with actual normal-batch report/export completion and next-member progress;
a completed seed XML or launched process alone is insufficient.

Report planned/executed/failed/remaining counts, actual fitness/trade observations,
selection rationale and limitations. Seed fitness is research evidence, not live
robustness or a promised return.

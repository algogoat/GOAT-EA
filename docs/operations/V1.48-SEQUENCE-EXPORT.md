# V1.48 sequence evidence in batch exports

User-approved scope: record sequence evidence during the fixed backtests that the
normal batch exporter already runs for selected candidates. The separate September
25 research capture remains paused. This change does not authorize a VPS rollout.

## Export contract

Keep each matching CSV, SET and `<same-stem>.goatseq` folder together. The folder
contains the native logical sequence lifecycle, owned orders/deals, realized costs,
sampled floating equity, account observations, exact effective settings and a
versioned manifest. The manifest binds the final CSV and SET bytes and is published
only after the evidence is closed. Adjusted-lot exports get their own evidence;
evidence from the earlier sizing cannot be attached to the adjusted SET.

Capture is for selected fixed export passes, not the genetic optimization or live
trading. It adds export time and disk use. Raw observations use broker server clock
coordinates, not UTC. A temporary zero-volume interval does not end a logical
sequence. Final tester closes must be included and cash/marks must reconcile.

## Builder workflow

Import the containing export folder or ZIP into a compatible Command Center
Optimizer. Preserve `.goatseq` directories when copying or archiving the exports.
The importer verifies identity/completion and prepares the evidence cache. Select
the eligible strategy pool, then use exposure-filter construction with explicit
member, asset, strategy-family and asset/family limits.

CSV/SET-only libraries remain usable for ordinary construction. They do not gain
sequence evidence retroactively, and importing them must never launch MT5.
Incomplete or mismatched evidence cannot be presented as exposure-filter-ready.

The comparison replays recorded sequence paths with admission filtering. It does
not rerun the EA's later signals or sizing after suppressing a sequence. Drawdown
is sampled, coverage gaps remain explicit, and choosing/evaluating subsets on the
same history is not independent validation.
